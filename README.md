# Statement Markup Tool

**A clean and easy-to-use desktop application that lets you markup prices in PDF or Word documents using plain English instructions.**

---

### Quick Start (For Non-Technical Users)

1. Go to the top right of this page and click the green **"Code"** button.
2. Click **"Download ZIP"**.
3. Extract the downloaded ZIP file to your Desktop (or anywhere you like).
4. Open the extracted folder.
5. Double-click the file named `Start Cost Markup Tool.bat`.

The program will launch automatically (first time may take 1–2 minutes).

---

## How to Use

1. Double-click `Start Cost Markup Tool.bat`
2. Click **Select PDF or Word File**
3. Type your instructions in plain English in the big box
4. Click **Process Document**
5. Use the **Make Adjustments** button if you need to make changes

## Example Instructions

- "Markup all prices by 1.35 except Product Supply and Installation which should be 1.38"
- "Add Net Total, HST at 13%, Total, Deposit and Balance"
- "Change Product Supply to 1.40"
- "Add $5000 to the deposit"

## Features

- Works with PDF and Word (.docx) files
- Understands plain English instructions
- Smart price detection and custom multipliers
- Optional rounding to whole dollars
- "Make Adjustments" button for quick fixes
- Creates clean professional output
- Never modifies your original file

## Output

Revised documents are saved in a folder called `Revised` next to your original file.
